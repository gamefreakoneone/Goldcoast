# Status

Sample spec: format reference only, not tracked in FEATURE_STATUS. Copy these headings into a numbered spec's `status.md`.

## Status

One of: Not started, In progress, Blocked, Completed. Must match the row in `docs/FEATURE_STATUS.md`.

## Evidence

For each validation step in `tasks.md`, the command that was run, the date, and the relevant output. Include test counts, lint results, and for manual checks a short description of what was observed in the CLI or web UI. Link to artifacts under `output/runs/<run_id>/` when a real run was used.

## Blockers

Anything preventing progress, who or what resolves it, and the date it was raised. Empty when there are none.

## Change Log

- YYYY-MM-DD: what changed in this spec's documents or status, and why.
