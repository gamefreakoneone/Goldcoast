# Design

Version new jobs through creative_type and include_story fields while jobs lacking them retain legacy behavior. Extend CreativeBrief with caption, panels and testimonial quote fields and CreativeArtifact format with post/story. Add social compositor using controlled text and original product photos; comic illustrations use four image calls with two retries maximum. Recompose Story from same art. Testimonial jobs use at most two model calls and one video analysis; save versioned transcript resources with explicit approved excerpt IDs and attribution. Campaign start snapshots the approved excerpt; execution verifies it remains approved and unchanged. Exact quotes and panel/caption promotions are validated. Add PUT /testimonials/{id} for review and POST /testimonials/analyze for analysis. Approvals/export require every requested placement, preserving legacy pairs.
