# Design: branded creative production

Add studio/creative.py with CreativeBrief, CreativeVerdict, CreativeArtifact, typed brief validation, bounded generation and CreativeService; studio/compositor.py with escaped, deterministic brand templates and headless Chromium rendering. Playwright is used as the backend Chromium rendering library, using installed Chrome locally and bundled Chromium in deployment; user-facing QA will still use Chrome computer use. Block all renderer network requests and embed supplied images/fonts as data URLs. Measure text and document bounds before capture, adapt font size deterministically, then reject unresolved overflow. Palette values are validated hex; generated HTML is never accepted from a model.

The worker adds brief and per-format attempt stages after campaign selection. Pass actual image bytes for reference assets to Gemini image generation; use the uploaded logo/font only in controlled composition. Use the existing recorded Gemini client through durable model/image reservations. Judge receives final composite plus brief and brand references. Passing requires every criterion >=7 and no critical issues. Completed judged attempts become tenant creative resources whose ID keys private PNG bytes. Human decision is versioned. Approval and export re-check source job snapshot versions, expiration and passing verdicts; replay is labeled separately by 0016. ZIP exports contain both approved formats and a manifest with evidence and verdicts. The original Olympics ad models remain unchanged; studio creative references the authenticated business snapshot and brand ID instead of seed athlete/style IDs.
