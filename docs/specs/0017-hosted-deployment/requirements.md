# Requirements: hosted deployment

Prepare and validate a deployable AWS demo in us-west-2 using the existing React/FastAPI/worker/PostgreSQL app. Public HTTPS via CloudFront default hostname; private frontend S3 origin, private ALB API origin, Cognito invitation-only PKCE, ECS Fargate API/worker, private RDS PostgreSQL, encrypted private asset S3, persistent private recordings, Secrets Manager and CloudWatch. No legacy unauthenticated API deployment. Live grants start zero and global live stays paused until explicitly enabled. Packaged replay works without provider credentials. Never include .env or local output in image/build context. Provide a concrete monthly cost estimate, deploy/teardown/account invitation instructions, health checks, migrations, least-required role permissions and a testable CDK stack.

Deploy only to the user's selected authenticated AWS account after a concrete cost/configuration review. If credentials/account are unavailable, finish all local build/synthesis/container validation and document that live provisioning is blocked; later submission preparation may proceed while this spec is explicitly Blocked. Do not claim a live URL before successful deployment and HTTPS/login/replay verification.
