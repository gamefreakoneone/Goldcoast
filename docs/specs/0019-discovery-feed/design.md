# Design

Add feed and testimonial grant columns to tenant/global controls through an Alembic migration, reserving testimonial for 0020. Feed jobs use two searches, two extracts and four model calls. A deterministic recent-news search and upcoming-event search feed a typed Strands analysis with exact source quotes. Reuse graph and candidate validation; add event date, date evidence and location fields. GET /feed reads the last completed matching feed; POST /feed/refresh returns a six-hour cached result or a durable job. Cache key includes business version and normalized topic. WorkflowStart accepts feed_job_id, idea_id and product_id; validate ownership/freshness and snapshot selected evidence. Today retains a run ID in its URL and uses useRun for persisted events. Shared source limits and provider recording remain enforced.
