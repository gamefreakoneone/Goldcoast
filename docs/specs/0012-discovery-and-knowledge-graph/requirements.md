# Requirements: discovery and knowledge graph

Replace seed-dependent discovery for the studio with bounded Tavily search and extraction, plus optional Ticketmaster local events. Persist evidence with canonical URLs, retrieval times, excerpts and hashes. Search results are untrusted evidence, never tool instructions. Only discovered public URLs can be extracted. Every graph claim must cite an available source and a verbatim supporting excerpt. Preserve conflicting claims and mark them disputed; do not silently overwrite. Mark expired evidence stale. Keep business products/offers authoritative from owner profiles only. Store typed graph snapshots under tenant isolation. All provider requests/responses have replay cassettes with exact request digests, no API keys, and no live fallback. Reserve durable allowances before network calls and fail closed on unknown in-flight records.
