# 0022 Live signals

Eligible live campaigns check the business-local daily Open-Meteo forecast before planning. Weather is optional, recorded, metered, cited, and visible in Review. Missing weather never fails planning; cancellation and lease loss still stop work. Product, testimonial, feed, brand and replay jobs make no weather requests. Legacy Olympics code is excluded.

One live campaign credit is authorized for validation across 0022 and 0023. Preserve its two placements for Telegram validation.
