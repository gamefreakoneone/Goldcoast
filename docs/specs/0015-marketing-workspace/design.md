# Design: marketing workspace

Keep React/Vite and introduce web/src/marketing components, types, authenticated client and OIDC module. Use a restrained editorial workspace: ivory canvas, forest-green navigation/primary actions, charcoal text, orange accents, serif page titles and clean sans-serif controls. Left navigation: Today, Brand library, Business, Campaigns, Settings. The Today screen has a chief brief composer, replay/live control, a supporting brand-readiness summary, and a lower workflow/evidence/result area. Brand library uses a visual upload collection plus editable extracted kit. Review shows actual landscape/portrait media, judge scores, source context and explicit decisions. History is a compact list; settings expose account/global usage and owner grants/kill switch. Generate primary and brand/review image concepts before coding; document exact tokens and any necessary deviations after inspection.

OIDC auth uses a short-lived sessionStorage PKCE verifier/state only during redirect. Access/refresh tokens remain in module memory, never localStorage. A refresh/relogin recovers on reload using provider session. Validate callback state, remove authorization code from URL, and use refresh single-flight for concurrent requests. Fetch authenticated private images into revocable object URLs. SSE uses fetch streaming with Authorization and Last-Event-ID, handles chunk boundaries, aborts on navigation/logout, refreshes auth when necessary and resumes durable events. Load independent initial resources concurrently. Forms send explicit expected versions; distinguish unconfirmed drafts from active brand kits. Keep model/provider details out of normal business controls except usage/replay information that affects cost.
